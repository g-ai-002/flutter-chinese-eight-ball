# 中式黑八 🎱

基于 Flutter + Flame 的中式黑八台球游戏，支持 Android、Windows 与 Web。真实物理、开放球台首球定组、四档可调 AI、AI 配置码、黑八指袋、自由练习球型、逐杆回放、对局数据导出与按天走势、自由球摆放、瞄准辅助与运行时合成音效，全部本地运行。

## 功能

- 🎯 标准九尺台：2.54 × 1.27 米台面、57.15 mm 球径、六个袋口与开球线
- ⚙️ 真实物理：固定子步长积分、等质量弹性碰撞、库边反弹、滚动摩擦、落袋判定
- 📖 完整规则：开球重摆、开放球台首球定组、犯规交换球权与自由球、黑八指袋胜负
- 🤖 人机对战：入门 / 进阶 / 高手与自定义四档，AI 枚举进球线路并用真实物理试算挑杆
- 🎚️ 自定义强度：滑杆在入门与高手之间插值候选线路、瞄准误差与力度误差
- 🔗 AI 配置码：把当前难度与强度复制成 `CEB1-…` 配置码，在另一台设备粘贴恢复
- 🛡️ 防守 AI：没有进球把握时轻碰藏球、贴库并把母球留在远离对手目标的位置
- 🧭 走位评分：按下一杆最优线路（切角、距离、袋口与阻挡）评估母球停位
- 👥 双人同屏：同屏轮流击球，适合面对面切磋
- 🎯 黑八指袋：清台后点击袋口指定目标袋，落入非指定袋口判负，AI 自动指袋
- 🧪 自由练习：无回合与犯规限制，任意摆球、母球自动回位、一键重打上一杆
- 🧩 球型模板：标准开球、直线球、贴库球、角度球、长台直线、翻袋球、薄球与堆球八种场景
- 📼 最近对局：自动保存最近 10 场，逐杆回放支持播放 / 暂停、跳杆与进度拖拽
- 📊 数据统计：胜率、场次、场均杆数、进球率、单杆最多、连续进球与难度表现
- 📈 近期走势：近 8 场柱状走势展示单场进球率，圆点标记人机胜负
- 📅 按天趋势：近 7 天柱状活动展示单日进球率，无对局的日期留空
- 📤 数据导出：把总览与最近对局汇总为纯文本，一键复制到剪贴板
- 🖱️ 操作：拖动球台瞄准、点击球体吸附球心、力度滑杆与 0.3° 微调
- 💡 瞄准辅助：幽灵球撞击点、目标球去向与库边落点，可随时关闭
- 🎨 三套球台配色（翡翠台呢 / 午夜蓝 / 酒红呢）与深浅色主题
- ✨ Flame 渲染：台呢渐变、木框、袋口、球体高光、出杆球杆与落袋动画
- 🔊 运行时合成音效（出杆 / 撞击 / 落袋 / 犯规 / 终局）与背景音乐，支持震动反馈
- 📱 响应式：手机 / 折叠屏 / 平板 / Windows 窗口自适应，宽屏侧栏、窄屏底部控制
- 🌓 简体中文界面，Windows 优先 `Microsoft YaHei UI`，Web 使用 soup_fonts 思源黑体
- 🧾 日志按天写入用户目录，设置页可查看最近日志

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 里手动运行 `build` 工作流，选中 `v*` Tag 时按该 Tag 的版本构建 Android / Windows / Web 并发布 Release，运行 `main` 则产出预览产物。音频在运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件。

本地无需安装 Android SDK 等大型工具链。

## 日志位置

- Windows：`文档/FlutterChineseEightBall/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterChineseEightBall/logs/`
- Web：仅保留内存日志，可在设置页查看

对局记录（最近 10 场）与逐杆回放保存在本机应用偏好存储中，不上传任何数据；可在「最近对局」页导出为纯文本到剪贴板，或删除单条 / 清空。AI 难度与强度可通过设置页的配置码在设备间复制迁移。

## 规则要点

开球后球台开放，首个合法落袋的球决定双方球组（1-7 全色、9-15 花色）。清空本方七颗球后，先指定袋口再合法打进 8 号黑八获胜；黑八落入非指定袋口、提前落袋或与母球同落均判负。母球落袋、空杆、先碰对方球或碰撞后无球碰库均判犯规，对手获得自由球。自由练习模式不判定回合与犯规，可任意摆球并重打上一杆。每局人机或双人对战结束后自动保存逐杆记录，可在「最近对局」中逐杆复盘；首页「数据统计」汇总本机胜率、杆数与进球表现。AI 在进攻把握不足时会主动防守，优先把母球留在远离对手目标、贴库或被遮挡的位置。
